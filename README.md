# VBIG Lab
---

This repository serves two purposes:

1. An annotation platform for human-written insights from Tableau Public dashboards, used as ground truth for evaluating VLM-generated outputs.
2. A file archive for the scraper, dataset, VLM inference, evaluation scripts, and the benchmark dataset accompanying the master's thesis.

---

> Part of the VLMs for BI Dashboard Insight Generation (**VBIG**) project.
