# VBIG Benchmark Dataset

**Thesis:** Automated BI Dashboard Narration: An Empirical Study of Small Vision-Language Models for Multi-Level Semantic Insight Generation  
**Author:** Mohamad Pradana Aditya  
**Institution:** Aarhus University, Department of Economics and Business Economics

---

## Overview

This repository contains all data produced in the empirical study evaluating seven open-source small Vision-Language Models (VLMs, ≤3B parameters) on their ability to generate semantically structured insights from multi-chart BI dashboard images. The benchmark consists of 40 dashboard images sourced from Tableau Public using the Superstore dataset, paired with human-written ground-truth annotations structured across three semantic levels (L2, L3, L4) following the Lundgard and Satyanarayan (2022) four-level model of semantic content.

Full methodological details are provided in the thesis.

---

## Files

### 1. `metadata.csv`
Dashboard-level metadata for all scraped dashboards.

| Column | Description |
|---|---|
| id | UUID primary key |
| dashboard_name | Name of the Tableau Public dashboard |
| dashboard_link | URL to the original dashboard on Tableau Public |
| dashboard_author | Tableau Public username of the dashboard author |
| bucket_path | Storage path to the dashboard screenshot image |
| created_at | Timestamp of record creation |
| favorite_count | Number of favourites on Tableau Public at scrape time |

### 2. `human_insights.csv`
Ground-truth annotations produced by the primary annotator for all 40 dashboards, along with two peer annotators for the 10-dashboard inter-annotator agreement (IAA) subset. Each row corresponds to one dashboard.

| Column | Description |
|---|---|
| id | UUID primary key |
| metadata_id | Foreign key linking to metadata.csv |
| expected_dataset | Boolean; TRUE if dashboard uses the correct Superstore dataset |
| insight_part_1 | Annotator 1 (primary) insight text |
| insight_part_2 | Annotator 2 (peer) insight text; populated for IAA subset only |
| insight_part_3 | Annotator 3 (peer) insight text; populated for IAA subset only |
| irr_flag | Boolean; TRUE for the 10-dashboard IAA subset |
| rejection_reason | Exclusion reason if dashboard was rejected (NULL for included dashboards) |
| created_at | Timestamp of initial annotation |
| updated_at | Timestamp of last update (annotator 1) |
| updated_at_2 | Timestamp of last update (annotator 2) |
| updated_at_3 | Timestamp of last update (annotator 3) |

**Note:** The 40 dashboards used in evaluation have expected_dataset = TRUE and rejection_reason IS NULL. Insight text is structured as "Chart N: [L2 sentence] / [L3 sentence] / [L4 sentence]" per chart, separated by newlines. 

Reproducing the evaluation pairing requires a parsing step that extracts individual chart blocks by matching "Chart N:" prefixes and splits each block by semantic level. The full parsing logic is described in thesis section 3.6.

### 3. `vlm_outputs.csv`
Raw inference outputs for all selected models across all 40 dashboards.

| Column | Description |
|---|---|
| id | UUID primary key |
| metadata_id | Foreign key linking to metadata.csv |
| model_name | Short model identifier (e.g. qwen3.5-2b) |
| model_hf_id | Full Hugging Face model ID (e.g. Qwen/Qwen2.5-VL-2B-Instruct) |
| raw_output | Full raw text output generated by the model |
| inference_success | Boolean; TRUE if inference completed without error |
| error_message | Error message if inference_success is FALSE; NULL otherwise |
| inference_ms | Inference time in milliseconds |
| created_at | Timestamp of inference |

**Models included:** Qwen3.5-2B, Qwen3.5-0.8B, Qwen3-VL-2B-Instruct, InternVL2-2B, InternVL2-1B, InternVL3-1B, moondream2. SmolVLM-256M-Instruct.

**Note:** The same parsing logic described in `human_insights.csv` applies here to extract chart-level blocks and semantic-level sentences from `raw_output` before pairing with ground-truth references. The parsed and paired outputs with their corresponding evaluation scores are available in `eval_scores.csv`, where generated and reference columns already reflect the post-parsing state.

### 4. `eval_scores.csv`
Evaluation scores per model-dashboard-chart-level pair, produced after output parsing and pairing with ground-truth annotations.

| Column | Description |
|---|---|
| id | UUID primary key |
| model_name | Short model identifier |
| metadata_id | Foreign key linking to metadata.csv |
| dashboard_name | Dashboard name (denormalised for convenience) |
| chart_id | Chart number within the dashboard (integer) |
| chart_title | Chart title as parsed from model output |
| level | Semantic level: L2, L3, or L4 |
| generated | Parsed generated insight sentence |
| reference | Paired ground-truth insight sentence |
| generation_success | Boolean; TRUE if a parseable output existed for this pair |
| degenerate_pattern | Degenerate output pattern label if detected; NULL otherwise |
| rouge1 | ROUGE-1 F1 score |
| rouge2 | ROUGE-2 recall score |
| rougel | ROUGE-L F1 score |
| bertscore_f1 | BERTScore F1 (rescaled with baseline, roberta-large) |
| geval | G-Eval score normalised to [0, 1]; populated for L3 and L4 only |
| geval_reason | G-Eval judge reasoning text; populated where geval is not NULL |
| created_at | Timestamp of score computation |

**Note:** BERTScore is computed with `rescale_with_baseline=True` using `roberta-large`. G-Eval uses GPT-4o as judge via the deepeval library with token probability weighting. L2 pairs use ROUGE and BERTScore only; L3 pairs use all three metrics; L4 pairs use G-Eval only.

SmolVLM-256M-Instruct entries are present in this file but were excluded from all reported results in the thesis due to 100% degenerate output patterns, identifiable via the `degenerate_pattern` column.

## Semantic levels

| Level | Name | Description |
|---|---|---|
| L2 | Quantitative facts and relations | Factual narration of chart values, rankings, and comparisons |
| L3 | Perceptual and visual phenomena | Pattern interpretation including trends, anomalies, and distributions |
| L4 | Contextual and domain-specific insights | Broader business implications and contextual interpretation |

L1 (chart construction properties) is excluded by design. See thesis section 3.2.1 for full rationale.
